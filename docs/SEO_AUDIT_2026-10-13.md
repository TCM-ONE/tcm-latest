# TCM One SEO Audit & Implementation Status

Date: 2026-10-13
Preferred canonical domain: https://thecodemunk.in
Timezone: Asia/Kolkata

## Executive Summary

The site is a static HTML plus PHP application served through Apache rewrite rules. Public course and workshop routes already exist as server-rendered pages (`/courses/{slug}`, `/workshops/{slug}`), which is better for SEO than the older `course-details.html?course=...` and `event-details.html?event=...` pages.

The first implementation pass focused on safe technical SEO, canonical linking, analytics, structured data, workshop accuracy, and claim cleanup without changing the approved visual design.
